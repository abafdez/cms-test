A fenced block whose language is one of our components becomes that component, the same way in the built page and in the CMS preview:

```yt
src: https://www.youtube.com/watch?v=gd5uJ7Nlvvo
title: Plain Text, by Dylan Beattie (NDC Copenhagen 2022)
caption: No thumbnail yet, so it shows the tile.
```

Any other code block stays code:

```js
const answer = 42;
```
